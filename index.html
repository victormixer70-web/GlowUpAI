      J.A.R.V.I.S

      Controla hologramas 3D con las manos y con la voz.
      Necesita permiso para la cámara y el micrófono. Funciona mejor en Chrome o Edge.

      MANUAL DE OPERACIONES

      GESTOS CON LAS MANOS

      ☝️ Apuntar con el índiceMueve el cursor. Mantenlo sobre un holograma para seleccionarlo.
      🤏 Pinza (pulgar + índice)Agarra el holograma y muévelo. Acerca o aleja la mano para traerlo o alejarlo.
      ✋ Mano abiertaGira el holograma seleccionado. Suelta con un movimiento rápido para lanzarlo girando.
      ✊ PuñoFrena el giro.
      🤏🤏 Pinza con las dos manosSepara las manos para agrandar, júntalas para encoger, gíralas como un volante para rotar.
      ✋✋ Abrir las dos manos de golpeVista despiezada (como Tony Stark). Júntalas rápido para volver a montar.

      COMANDOS DE VOZ

      «Crea un reactor / cubo / esfera / pirámide / toro / nudo / planeta / átomo / ADN»Materializa un holograma.
      «Despiézalo» / «Explota» · «Móntalo»Vista despiezada y volver a ensamblar.
      «Gira» · «Para»Rotación automática.
      «Más grande» · «Más pequeño» · «Al centro»Tamaño y posición.
      «Color rojo / azul / verde / dorado / morado / rosa / blanco»Cambia el color.
      «Siguiente» · «Anterior»Cambia de holograma seleccionado.
      «Escanéalo» · «Analiza»Informe del holograma.
      «Borra esto» · «Borra todo»Elimina hologramas.
      «¿Qué hora es?» · «¿Qué día es?»Hora y fecha.
      «Jarvis, …» cualquier preguntaResponde con el núcleo de IA (Gemini, la misma clave que GlowUp).
      «Jarvis, hazme un resumen / tarjetas / examen / plan de clase / rúbrica sobre …»Crea material de estudio y lo muestra en el panel de documentos.
      «Jarvis, enséñame cómo es un átomo de carbono» · «pon tres planetas en fila»La IA crea y mueve hologramas por ti.
      📎 o arrastrar un archivo · «resume esto»Analiza fotos, PDF y apuntes adjuntos.
      «Jarvis, mira esto» · «¿qué ves?»Hace una foto con la cámara y la analiza.
      «Lee el documento» · «Cierra el documento» · «Calla»Controla el panel de documentos y la voz.
      «Nueva conversación» · «Abre la memoria»Memoria compartida con el chat de GlowUp.
      «Silencio»Desactiva el micrófono.

      SIN CÁMARA

      Ratón / dedoClic para seleccionar y arrastrar. Rueda para escalar. Mayús + arrastrar para girar. Doble clic para despiezar.
